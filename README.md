# Home Assistant: Das Masterhandbuch. Der Begleiter

Begleitmaterial zum Buch **"Home Assistant: Das Masterhandbuch. Von den ersten Schritten bis zur KI-gestützten Hausautomation"** von Thomas Giehl.

Der Begleiter ist ein Paket aus Textdateien, das du in deinen Chatbot lädst (Claude, ChatGPT, Gemini oder Microsoft Copilot). Er kennt den Aufbau des Buchs und das Wichtigste aus jedem Kapitel und hilft dir, den Stoff auf dein eigenes Zuhause anzuwenden. Den Buchtext ersetzt er nicht.

## Herunterladen

1. Öffne rechts auf dieser Seite **Releases** und lad die Datei `ha-masterhandbuch-begleiter.zip` der neuesten Fassung herunter.
2. Entpack sie. Das Passwort steht am Anfang von Kapitel 0 im Buch.
3. Folge der Anleitung in Kapitel 0 oder der Datei `0_einrichtung_….txt` im Ordner deines Chatbots.

## Inhalt des Pakets

| Ordner oder Datei | Inhalt |
|---|---|
| `claude` | Skill als ZIP-Datei, dazu ein Unterordner `projekt` als zweiter Weg |
| `chatgpt` | eine Anweisung und drei Wissensdateien für ein Projekt |
| `gemini` | der Begleiter in einer Datei, dazu eine Startnachricht |
| `copilot` | dasselbe für Copilot und jeden anderen Chatbot, der Dateien annimmt |
| `begleiter_anfaengerfehler.md` | die dusseligen Anfängerfehler aus Anhang E, zum Anhängen bei Bedarf |
| `LIESMICH.txt` | die Kurzfassung |

Erstes Stichwort zum Ausprobieren: `Begleiter: Wo fange ich an?`
Wird der Begleiter zu lang oder stellt viele Fragen auf einmal: `Halte dich an deine Regeln.`
